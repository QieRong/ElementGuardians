Noto Sans SC / Noto Sans KR are distributed under SIL Open Font License 1.1. See OFL.txt. Copyright and license metadata remain embedded in the downloaded font files. The font files have not been locally modified or renamed internally.

These small character subsets were returned by the official Google Fonts CSS API for the current design text. Original CSS responses, exact URLs, sizes and SHA256 values are retained in SOURCE.json and the adjacent provenance CSS files. Those provenance CSS files are not imported by the preview. The preview loads only local binary files.

The subsets are not complete game fonts. Adding UI text requires regenerating the subsets, rechecking coverage and preserving license/attribution. No proprietary Windows system font files are distributed.

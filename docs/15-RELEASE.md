# 15｜Windows 导出与作品集演示

## 先决条件
P0/P1测试通过后再导出。Godot 4.4.1需安装与引擎版本匹配的 Windows Export Templates。本准备包不包含引擎或模板，不声称已导出 EXE。

## 推荐导出物
- `ElementGuardians.exe` 与必要的PCK/资源文件（根据 Godot 导出设置）
- `README-PLAY.md`：操作说明、机器和测试范围、已知问题
- `configs` 的可核查数值源表（作品集附录）
- Demo短视频、关键截图、CHANGELOG与许可登记

## 最低验收
从一个全新解压目录打开、能进入菜单、召唤、合成、开波、完整战斗到结算、重开；配置不依赖绝对磁盘路径。测试输出包括Godot版本、Windows版本、进程退出、实机截图、已知风险。外部干净机器没有实测就标为未验证。

## 不上传的文件
API密钥、本机绝对目录、缓存和大型临时构建产物、无版权许可素材、用户的私人文件。

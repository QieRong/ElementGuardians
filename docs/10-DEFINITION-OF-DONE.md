# 10｜完成定义（DoD）

## P0 完成定义
- 菜单、准备、战斗、结算完整贯通，不存在玩家无法继续的死状态。
- 3×3 共9格；3类守卫；同类同级合成Lv3封顶；6波；1个Boss；金币、基地生命与重新开始。

- 自动化与人工测试记录版本、seed、设备、结果、未覆盖项目；真人试玩按 `18-PLAYTEST-PROTOCOL.md` 留档。

- README 能指导面试官在自己的 Windows Godot 环境从项目启动至胜败演示。

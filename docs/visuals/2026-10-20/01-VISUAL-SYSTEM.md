# 两页共用视觉规范｜提案 v0.1

依据：[设计简报](00-BRIEF.md)、[现行 UI 规范](../../06-UI-UX.md)。本文件具体参数未制图、未实测，不替代 D009 的风格决定。

组件的原图对应、角色格内排法和缺口见[素材组件](03-ASSET-COMPONENTS.md)，不以本文件的风格提案替代素材元数据或字体测量。

## 视觉语法

纸张叠层承担结构，机械图腾承担识别，留白承担阅读。厚重纸纹集中在背景与边框；正文和数字底面减纹理。只用局部切边、角饰和柔和投影，不把每个按钮装饰成祭坛。

主菜单突出世界与开始入口；战斗页突出路径、九格与即时状态。战斗背景的细节强度应低于单位轮廓和功能图层；不能以大面积发光覆盖路线。

## 候选色板

| Token | 候选值 | 用途与限制 |
|---|---|---|
| ink-bg | #101C29 | 主背景、最深层 |
| ink-panel | #1C2B38 | 文字与 HUD 平面底板 |
| paper | #E8D9BC | 正文、纸层与轮廓 |
| paper-soft | #CBBCA2 | 次级文字；不直接放复杂背景上 |
| rust | #A34431 | 主按钮纸片、危险局部；必须另配文字或图标 |
| ice | #8BCAD1 | 选中框、冰元素；不单凭颜色表达选中 |
| lightning | #D8D45D | 雷元素、局部刻纹；不能铺满 HUD |
| fire | #E58A4D | 火元素、命中点，不用作通用正文 |
| quiet | #8D969B | 禁用文字与图标，配深底与锁定标记 |

这些颜色是制图起点。浅底用黑蓝字，锈红按钮优先用骨白字；颜色与纸纹叠加后的对比度需重新取样，不能从 HEX 表直接宣布可读。

## 文字与密度

| 层级 | 候选字号（设计 px） | 使用位置 |
|---|---:|---|
| 游戏标题 | 64 | 主菜单标题，不直接用于战斗页 |
| 页面主操作 | 32 | 开始游戏、开始第 n 波 |
| HUD 主值／按钮 | 28 | 波次、HP、金币、召唤 |
| 状态与说明 | 24 | 提示、禁用原因、格号、Lv |

- 功能性文字最低 24px；0.75 倍下等效 18px，仍须目检。装饰性小字不能承载必要规则。
- 文字使用独立层，避免依赖生成图里的文字作为最终素材；不把中文正文换成难读的秘文。
- 长提示最多两行，24px、建议行高 32px；超长内容移到后续帮助页，不挤压战场。
- 数字保留完整位数，右对齐或等宽数字；金币采用运行上界推导预留宽度，不能用“999+”掩盖实际账本。
- 字体文件暂未选择、未安装、未登记。候选必须有中文覆盖和可核查许可；未确认前不承诺打包分发。

## 间距、边框和纸层

- 普通面板内边距 16–24px；面板外间距 12–16px；页面文字安全边距 24px。
- 重要点击目标至少 60×60px；按钮提案高度 72–96px。棋盘按锁定 76px，不能为美观放大格子。
- 主要面板轮廓建议 2px，选中建议向格内画 3px；微细纸层仅作装饰，缩放后不可成为唯一状态信号。
- 按下位移建议 2px，以内缩纸层为主；不通过移走文字或改变点击区域表达按下。
- 柔和投影建议偏移 2–6px，避开格间 4px 缝；最终值待目检，不以阴影改变地图碰撞或可点击范围。
- 九宫格组件先测原图边框厚度再设 margin，不在本轮凭目测写死导入参数。

## 控件状态语言

| 状态 | 至少两种线索 | 文案要求 |
|---|---|---|
| 正常 | 清楚边缘＋平整字区 | 动作名明确 |
| 悬停／键盘焦点（后续实现） | 内轮廓＋角标 | 不改变动作含义 |
| 按下 | 内缩纸层＋小幅位移 | 文字保持清楚 |
| 选中 | 冰青内框＋格号／选中标记 | 底部说明所选格 |
| 可合成目标 | 双角标＋轮廓，不能和选中同形 | 说明“点击同类同级目标完成合成” |
| 禁用 | 降低装饰强度＋锁定／斜纹标记 | 同时给“未选空格／金币不足／战斗中”等原因 |
| 错误 | 警示符＋短句 | 不只闪红；不掩盖成功／失败是否改变资源 |

禁用不是把整块透明度降到看不清。锈红主操作与危险提示通过按钮位置、警示形状和文案区分。

## 元素、等级与特效

- 火：火焰轮廓＋“火”；冰：晶体／雪片轮廓＋“冰”；雷：闪电／折线轮廓＋“雷”。F／I／L 可用于诊断，不要求正式稿依赖英文缩写。
- Lv1／Lv2／Lv3 用同一个角标位置；Lv3 增加“满级”说明的状态局部图，不新增第四等级。
- 76px 格中优先保留面部主体与元素轮廓，纸饰可裁出缩略图但不重绘成其他角色；明确不等于已修复原图。
- 攻击范围不常驻堆叠显示；概念中如展示选中范围，标注其状态，不将圈定范围解释成手动技能。
- 命中与减速特效不遮挡血条、路线箭头、元素标识。雷不生成未定义的无限分叉；火不暗示已有持续燃烧机制。

## 图层顺序

背景远景 → 背景暗化／减纹理 → 功能路线 → 棋盘底与格号 → 基地与单位 → 单位标识与血条 → 克制的命中特效 → HUD／操作区／提示。

地图与 HUD 的坐标层相互独立，装饰层不接收鼠标事件。若后续接入引擎，需验证点选穿透和遮挡，而不能仅凭这一图层表宣称通过。

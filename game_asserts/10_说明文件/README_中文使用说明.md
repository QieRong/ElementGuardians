# 元素守卫｜纸雕秘仪风 · 独立素材包 v2.0

## 下载与使用
本包有 **58 张独立 PNG**，不是图集。每个角色/敌人/图标/按钮/地块/特效/面板已拆分为单独中文文件名。
解压后将 01~09 分类文件夹整体复制到 Godot 工程 `assets/` 下即可导入。
场景里通过 Texture2D、TextureRect、Sprite2D、TextureButton 等按相对路径引用 PNG。

## 美术方向
**纸雕秘仪风**（Papercraft Techno-Occult Fantasy）：分层剪纸、哑光纸张、机械秘仪图腾与温和的克系异象；颜色以黑蓝、骨白、锈红、冰青、酸黄为主。
本套素材为专门生成的 AI 美术，未有意复制大梦龙途或现有游戏的角色与 UI。
**但任何生成式素材都不等于可以法律保证零版权风险**；本作品用作面试展示通常风险较低，仍建议保留生成记录，并在计划公开发行或商用前做相似性检索与权利审查。

## 首版游戏规格提醒
最初的《元素守卫》策划为 3 名守卫（火/冰/雷）、3 种普通敌人和一个 Boss，6 波敌人，3x3 棋盘。
素材里另有「虚空守卫」「自然守卫头像」和第 4 种怪物等拓展设计，这些只是美术备选，**不代表需要修改 AGENTS.md、Excel 数值表或游戏规则**。
如果要增加第 4 元素，必须先更新并确认 GDD/Excel/验收计划。
注意：头像集源自独立概念图，**部分头像与守卫立绘并不是同一角色的严格对应图**，需要人工审美核对，不要自动强行匹配。

## 关于拆图质量
- 01~07 分类使用原始高清合成图按排列切分、去除四周空白并置于透明正方形画布。
- 08 界面面板按不规则区域裁切，保留原比例。
- 09 背景为完整横屏版本，以及中心裁剪的竖屏预览版本（会丢失左右画面）。
- **这些素材是静态 PNG**，不包含逐帧角色动作、美术骨骼、碰撞体、九宫格切片设置、动态特效、字体或音频。动画/碰撞/自适应 UI 需在 Godot 内另做。
- 角色立绘较复杂，建议游戏战斗棋盘显示时适当缩小并检查可读性。
- 因源图上的装饰物可能靠得很近，少数裁切可能存在细小装饰被截断。若发现问题，应先对照源图重新调整裁切，不要盲目补像素。

## 建议用法
尽量不要再让代码 AI 重新生成新的临时美术。先按设计文档建立资源 ID 映射，并把贴图绑定在对应 Godot 节点中；启动游戏后再进行缩放、美术差异和棋盘遮挡测试。

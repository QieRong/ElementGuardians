## 3. 玩家状态与反馈

| 状态/操作 | 展示与响应 | 消费约束 |
|---|---|---|
| PREP选空位 | 225基础圈、225–235可能范围带、覆盖道路高亮；附近显示“随机召唤·20” | 选择不扣钱；类型面板仅说明概率 |
| 点召唤 | 校验成功后真实创建守卫，显示精确范围与出现反馈 | 成功扣20并抽一次独立召唤RNG；失败状态不变 |
| 选已有塔 | 名称、等级、准确射程、当前/升级后伤害及价格 | 点击另一塔仅切换，绝不合成或扣款 |
| 点升级 | 当前等级核价；原位升一级，金币和等级即时更新，短脉冲反馈 | 每次新有效点击消费一次；按住不连升，选中双击不升级 |
| 缺钱/满级 | 缺额说明/“已满级”，消费按钮禁用 | 即使直接调用命令也不能改变状态 |
| COMBAT查看 | 只读范围/属性，标明战斗中不可布阵 | 不暂停战斗、不消费、不抽RNG |
| 切换/取消/开波/重开 | 点空白或Esc关闭；切换清掉旧范围；阶段变化清理旧面板输入 | 不遗留回调、不误扣、不让装饰动画阻塞逻辑 |

面板沿用不透明纸雕底与Lucide功能图标，候选位置避让HUD、出口和被选塔；靠边翻转并限制在可视区域。稳定点击区，防止点击面板穿透棋盘。鼠标/键盘焦点可辨，取消后恢复合理焦点。720×1280、540×960和六语言均须验收，长价格/说明不截断。声音使用现有设置，反馈同时有视觉；动画始终开启，不新增开关。

范围绘制来自生产守卫属性及世界坐标，与角色动画缩放无关；预览高亮不得承诺可击杀。对连续两个独立升级点击可依次升到Lv3，但同一次输入事件不可重复提交；按下后发生阶段/目标变化应拒绝旧请求并重新读取状态。

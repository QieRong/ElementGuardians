## 制作标准
- 优先使用 Godot 原生绘制满足功能，无需从外部下载素材，避免侵权风险与 AI 额度浪费。
- 各资源建议 256×256 以上透明背景 SVG/PNG，自制时记录工具与 prompt；用于 2D 节点中要检查导入缩放。
- 禁止使用竞品商标、角色、特殊图标、美术截图及未经许可的图包。
- 任何外部资源逐项登记来源、作者、原始链接、许可版本、使用范围、是否允许再分发，放在 `tracking/ASSET_LICENSES.csv`。
- 不要声称 AI 生成素材没有版权风险；实际商用须独立审核，面试 Demo 则保持全部来源可追踪。

## P2 扩展边界
火/冰/雷待机动画、怪物受击反馈、波末强化卡演出、基础音效可作为锦上添花；任一素材制作不得阻塞 P0 可玩闭环。

## 素材接入规则
1. 以 `game_asserts/10_说明文件/独立素材清单.json` 为素材真值；复制或改名后必须在 `tracking/ASSET_LICENSES.csv` 记录“包内路径 → 工程路径”的映射，校验脚本按映射检查文件存在与 SHA256。
2. 建议按用途复制到 `godot/assets/characters|enemies|tiles|ui|fx|backgrounds/`，保留可追溯编号；若改 ASCII 文件名，映射表就是唯一对照，不允许只改文件不改表。
3. 导入 Godot 后检查：透明边缘无黑边、缩放后不糊、九宫格边框不变形、按钮禁用态仍可读。
4. 同一角色不要混用立绘与不同来源头像（包内说明已提示头像与立绘并非严格同一角色）；界面头像需与场上单位一致或明确标注为概念图。
5. 备选资产（004 虚空守卫、043 自然头像、044 虚空头像、008 Boss 候选、045–048 异兽头像、012 虚空元素、015 召唤图标、026–029 元素地块）**不计入 P0**；采用任一项都要先改规则文档与配置，不得只换图。

## 许可与来源登记
- `tracking/ASSET_LICENSES.csv` 目前只有表头，尚未登记这 58 张素材；接入前必须补齐：包版本 v2.0、生成方式（AI 生成）、生成/整理日期、原始说明文件路径、使用范围（面试 Demo/非商用）、是否可再分发、与竞品的相似性自查结论。
- README 已声明“生成式素材不等于零版权风险”；文档、作品集与面试讲述中不得写“无版权风险/完全原创无参考”。公开发行或商用前需独立做相似性检索与权利审查。
- 禁止把竞品截图、角色、UI 布局、数值表直接作为素材或改色件（见 `12-ORIGINALITY.md`）。

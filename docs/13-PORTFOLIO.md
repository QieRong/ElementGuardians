# 13｜游戏策划求职作品集证据计划

**用途**：应聘游戏系统/数值/战斗/关卡策划，证明个人“提出问题→制定规则→配置数值→验证→复盘”的能力，而非靠代码量包装。

## 推荐作品集结构（完成后PDF/网页版，可另做）
1. 封面：元素守卫—2D 合成塔防玩法策划 Demo、本人职责、AI 协作说明。
2. 30秒核心玩法介绍与1分钟实机视频。
3. 目标用户、核心循环、选题理由和与竞品的差异（不靠复制素材）。
4. 系统策划拆解：召唤、合成、战斗、强化、胜败条件与异常处理。
5. Excel 表：展示塔、敌人、波次、强化4表的实际配置，包含公式、问题与修改前后对比。
6. 关卡：6波递进目标、怪物和时间分布、玩家失败原因。
7. 问题闭环：至少2个真实BUG、1个数值不平衡案例，包含复现、修改、证据。
8. 结果与反思：严格区分代码测试、个人实机测试、真实玩家测试。

## 实测记录字段
`日期,commit,Godot版本,设备与分辨率,seed,局长秒数,胜负,第几波失败,失去HP,击杀,漏怪,操作策略,数值调整,复验结果`。
测试尚未执行时不得填具体胜率和平均用时。

## 个人职责写法
“主导玩法和数值设计、制定关卡与合成规则、整理Excel配置和验收清单；AI辅助GDScript实现，本人审查逻辑与游戏体验、记录迭代结果。” 其中“主导”应限定本人确实决定的部分，如AI先给方案、用户未审查则不能借用表述。

- 三选一升级截图
- 第一波和Boss波的对比
- Excel 真实表格与计算公式
- 2项Bug复现/修复证据
- 至少3位真实试玩者的匿名反馈（如果确实招募）
